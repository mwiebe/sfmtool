# Local cluster test cases

Labelled seed neighbourhoods for benchmarking **local cluster-determination
strategies** (given a seed descriptor's neighbours, which form its track cluster?)
without re-querying the index or running a solve.

- Generated by `../exp20_make_cluster_cases.py`, benched by
  `../exp21_cluster_strategies.py`.
- One `<dataset>.npz` per `sfm_descriptors.SOLVES` entry (incl. `dino_large`, the
  cluster matcher's own denser dino solve). Ground-truth tracks come from that
  solve, so co-observation labels are only as complete as it is.

Each `.npz` holds `S` seeds × `KB=48` neighbours (sorted by distance):

| key            | shape    | meaning                                              |
| -------------- | -------- | --------------------------------------------------- |
| `seed_global`  | (S,)     | seed's global descriptor index                      |
| `seed_image`   | (S,)     | seed's image index                                  |
| `seed_point`   | (S,)     | seed's track id (-1 if untracked)                   |
| `nb_global`    | (S, KB)  | neighbour global indices                            |
| `dist`         | (S, KB)  | neighbour L2 distances (ascending)                  |
| `image`        | (S, KB)  | neighbour image index                               |
| `point`        | (S, KB)  | neighbour track id (-1 if untracked)                |
| `is_coobs`     | (S, KB)  | **ground truth**: same track, different image       |
| `same_image`   | (S, KB)  | neighbour shares the seed's image (never a member)   |
| `rev_rank`     | (S, KB)  | rank of the seed in this neighbour's own list (0=absent) — for reciprocity |
| `dataset`,`kb`,`solve` | scalars | provenance                                  |

Seeds are ~2500 in-track (≥1 co-observation) + ~500 background (untracked, where
the right answer is "no cluster"), sampled with a fixed RNG seed.

A strategy is `case -> (S, KB) bool member mask`; score it against `is_coobs`.
See `exp21_cluster_strategies.py` for the interface and example rules.
